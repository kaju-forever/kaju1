## 🎵 How to Add Your Background Music

We created a dedicated folder for your music:
```text
wedding_anti/
└── assets/
    └── audio/
        └── wedding-song.mp3   <-- (Copy your MP3 file here)
```

1. Pick your favorite wedding song (`.mp3` format).
2. Rename the file to `wedding-song.mp3`.
3. Drop it inside the `assets/audio/` folder.
4. Refresh your browser, and clicking the floating music button will now play **your song**!
*(If no file is present yet, it automatically plays a soft Indian instrumental wedding track).*

## 📸 How to Add Your Pictures

We created a dedicated folder for your photos:
```text
wedding_anti/
└── assets/
    └── images/
        ├── hero.jpg        <-- Main full-screen background photo of Kavu & Jiju
        ├── bride.jpg       <-- Portrait photo of Kavu
        ├── groom.jpg       <-- Portrait photo of Jiju
        ├── gallery-1.jpg   <-- Memory / Pre-wedding photo 1
        ├── gallery-2.jpg   <-- Memory / Pre-wedding photo 2
        ├── gallery-3.jpg   <-- Memory / Pre-wedding photo 3
        ├── gallery-4.jpg   <-- Memory / Pre-wedding photo 4
        ├── gallery-5.jpg   <-- Memory / Pre-wedding photo 5
        └── gallery-6.jpg   <-- Memory / Pre-wedding photo 6
```

1. Save your photos as `.jpg` (or `.png`).
2. Name them as listed above and drop them into `assets/images/`.
3. Refresh your browser! The website will automatically display your custom photos.

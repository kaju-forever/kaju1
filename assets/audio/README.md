# 🎵 Wedding Music Folder

Place your wedding background music file here!

### Recommended File Name:
```text
wedding-song.mp3
```

### How it works:
- If you copy your MP3 file here named `wedding-song.mp3`, the website will automatically play your custom song!
- If no file is found yet, it automatically plays a soft royalty-free Indian instrumental wedding track from the web as a fallback.
- Supported formats: `.mp3`, `.m4a`, `.wav`, `.aac`.
